도형의 이동 탐구실

좌표는 어떻게 바뀔까요? 이동 방법을 선택하고 그래프를 비교해 보세요.

01 이동 설정

파란색은 원래 도형, 주황색은 이동한 도형입니다. 점선은 기준점의 이동을 나타냅니다.

02 좌표평면에서 관찰하기

원래 도형이동한 도형이동 경로 / 대칭 기준

표시 범위: −10 ≤ x ≤ 10, −10 ≤ y ≤ 10. 범위를 벗어난 부분은 잘려 보입니다.

03 핵심 개념

평행이동(x, y) → (x+a, y+b)
a>0: 오른쪽, a<0: 왼쪽
b>0: 위쪽, b<0: 아래쪽
방정식 F(x,y)=0은
F(x−a,y−b)=0으로 바뀝니다.
대칭이동x축: (x, y) → (x, −y)
y축: (x, y) → (−x, y)
원점: (x, y) → (−x, −y)
직선 y=x: (x, y) → (y, x)
관찰할 성질이동한 도형은 원래 도형과 합동입니다.
선분의 길이와 각의 크기는 유지됩니다.
원점 대칭은 원점을 중심으로 180° 회전한 것과 같습니다.
